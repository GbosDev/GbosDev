## 👨‍💻 Sobre mim

Estudante de **Sistemas de Informação (UNIRIO)**, focado em desenvolvimento web full-stack. Meus projetos vão de exercícios sólidos de POO e estruturas de dados em Java/Python até aplicações completas com back-end (Spring Boot, Python), front-end (Angular, JS puro) e banco de dados (MySQL, MongoDB).

- 🏗️ Já arquitetei sistemas multi-camada (FED → BFF → SRV) com Angular, Spring WebFlux e Spring MVC
- 🧪 Tenho experiência prática com testes de carga (k6) e análise de latência/vazão/concorrência
- 📊 Gosto de construir painéis e dashboards interativos orientados a dados reais
- 🔧 No trabalho, uso o ecossistema Atlassian (Jira, Bitbucket, Bamboo) para deploys de front-ends

## 🚀 Projetos em destaque

### Full-stack & arquitetura

**[Nexus Orbita](https://github.com/GbosDev/nexus-orbita)** — Plataforma de resiliência operacional com arquitetura em 3 camadas: Angular (FED) → Spring WebFlux (BFF) → Spring MVC (SRV), MySQL + MongoDB, tudo orquestrado via Docker Compose.
`Angular` `Spring Boot` `WebFlux` `MySQL` `MongoDB` `Docker`

**[PaperBank](https://github.com/thauanhub/paper-bank)** — Banco digital (SPA em Angular + back-end Python), com MySQL e MongoDB. Inclui testes de carga com k6 medindo latência, vazão e concorrência, e um ciclo de otimização comparando resultados antes/depois. Testes em **[TestesDeCargaK6-PaperBank](https://github.com/GbosDev/TestesDeCargaK6-PaperBank)**.
`Angular` `Python` `MySQL` `MongoDB` `k6`

### Painéis e dashboards

**[Bússola BSI](https://github.com/GbosDev)** — Painel de ocupação de salas de aula, com grade horária, prédio 3D navegável (CSS puro) e busca por disciplina. HTML/CSS/JS puros, sem build.
`JavaScript` `CSS3` `SVG`

**VagON** — App de acompanhamento de lotação de vagões do MetrôRio em tempo real (projeto de Empreendedorismo e Inovação).

**Painel de Saúde Materno-Infantil** — Indicadores de saúde pública (TMI, RMM, vulnerabilidade por município) a partir das bases SIM e SINASC do DATASUS.
